CV Builder

Version 1.2 · Open source (MIT License)

A free, open-source tool for building a professional CV in minutes. Design with total freedom, preview every change live, and export a polished PDF — no account required.

  • Interactive editor with live preview
  • 5 professional templates, custom colors & fonts
  • Reorder sections, toggle visibility, custom CSS
  • Optional profile photo
  • Random CV generator for inspiration
  • One-click PDF export & JSON backup
  • Installable app, works offline
